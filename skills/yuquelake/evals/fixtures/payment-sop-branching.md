# 企业缴费充值 SOP

## 目的
规范企业用户缴费充值操作流程，确保资金准确到账和额度及时补齐。

## 适用范围
适用于所有企业用户的充值缴费操作。不适用于个人用户充值。

## 职责分工

| 角色 | 职责 | 权限 |
|------|------|------|
| 值班客服 | 接收缴费信息、核对凭证 | 发起流程 |
| 财务阿飞 | 对公转账确认、额度补齐 | 资金操作 |
| 主管 | 审批异常情况 | 审批 |

## 操作步骤

### 步骤1：接收缴费信息
1. 企业用户在群内发送缴费信息（缴费方式、金额、凭证截图）
2. 值班客服确认信息完整性
3. 要求用户发送缴费凭证

### 步骤2：缴费方式分流（关键判断点）

根据用户选择的缴费方式，走不同处理路径：

**路径A：网站直接充值**
1. 用户在网站完成充值
2. 系统自动补齐额度
3. 值班客服确认到账
4. @用户确认额度

**路径B：对公转账**
1. 用户完成银行转账
2. 值班客服在语雀登记转账记录
3. 在群内公示转账信息
4. @阿飞操作补齐额度
5. 阿飞确认额度已补齐
6. @用户确认额度

### 步骤3：确认与归档
1. 确认额度已补齐
2. 保存缴费记录
3. 通知用户充值成功

## 注意事项

> ⚠ 对公转账必须留存银行回单截图，以备财务对账。

> ⚠ 额度补齐后必须由用户确认，不可由客服单方面确认。

## Check List

- [ ] 缴费凭证已确认
- [ ] 缴费方式已分流
- [ ] 额度已补齐
- [ ] 用户已确认
