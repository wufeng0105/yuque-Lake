# 不可变元素清单

> 本文件是内容保全的唯一权威定义。在整个转换流程中（Step 1 清洗 → Step 2 梳理 → Step 3 伪代码 → Step 4 输出），以下元素从输入到输出全程锁定——可以改变格式、可以移动位置，但不可删除、不可截断、不可改写。
>
> 各文档类型写作指南可以在此基础上追加更多保留规则，但不可缩减本基线。

## 为什么需要这份清单

转换流程分四步走，每一步都有不同的关注点：清洗关注格式剥离、梳理关注结构重组、伪代码关注语法选择、脚本关注编码转换。在每一步中，AI 都有大量自由裁量权——可以合并步骤、可以重组章节、可以选择不同的 Card 类型。

但这种灵活性不能以丢失内容为代价。一份 SOP 如果丢失了系统操作截图，读者就无法跟着操作；丢失了话术原文，客服就无法照着说。这份清单就是所有灵活操作的边界：在这份清单之内，内容不可变；在清单之外，AI 可以自由发挥。

## 不可变元素基线

| 元素类型 | 不可变性 | 保全规则 | 在清洗阶段的标记格式 |
|---------|---------|---------|-------------------|
| 图片 | URL 不可丢失 | 输出中必须包含输入中的每一个图片 URL | `[IMAGE: url \| alt说明]` |
| 链接 | URL 不可丢失 | 输出中必须包含输入中的每一个链接 URL（含 `<a href>` 标签链接、`<card name="yuque">` 嵌入链接、以及**正文中以 `http://` 或 `https://` 开头的纯文本 URL**） | `[LINK: url \| 链接文本]` |
| 代码块 | 内容不可丢失 | 输出中必须包含输入中的每个代码块的完整内容 | `[CODE: 语言]` 代码 `[END CODE]` |
| 表格 | 数据不可丢失 | 输出中必须包含输入表格的所有数据行 | `[TABLE]` 行1\|行2 `[END TABLE]` |
| 话术/口令 | 逐字保留 | 原文不可改写、意译、截断 | 包含在 `[QUOTE: 原文]` 或正文标记中 |
| 金额/数值 | 逐字保留 | 原始精度不可改变，金额计算公式不可改变 | 正文标记 |
| 附件 | 不可丢失 | 输出中必须包含输入中的每个附件 | `[FILE: src \| name \| ext]` |
| 数学公式 | 内容不可丢失 | LaTeX 原文不可改变 | `[MATH: LaTeX原文]` |
| Mermaid/流程图 | 内容不可丢失 | 图表代码不可丢失（可调整布局语法） | `[DIAGRAM: type]` 代码 `[END DIAGRAM]` |

## 保全规则的含义

"不可变"不等于"不可动"。以下操作是允许的：

- **改格式**：图片从 `<card>` 格式变 `<card-image>` 伪标签再变真实 `<card>` —— 格式在变，URL 不变
- **移位置**：图片从步骤内部移到折叠面板 —— 位置在变，图片不丢
- **改呈现**：话术从段落变为表格 —— 呈现在变，原文不改
- **补说明**：给图片加图注、给代码加注释 —— 在原有内容上增加，不减少

以下操作是禁止的：

- 删除任何图片 URL
- 删除任何链接 URL（包括 `<a href>` 标签链接、`<card name="yuque">` 嵌入链接、正文中纯文本 URL）
- 截断话术原文（如用"..."省略）
- 改写话术原文（如把口语化的话术改成书面语）
- 删除表格中的数据行
- 删除代码块内容
- 省略金额计算公式的任何部分

### 链接的完整定义

"链接"不只指数 `<a href>` 标签。以下三种形式都是链接，均不可丢失：

1. **`<a href>` 标签链接**：HTML/Lake 中的超链接标签
2. **`<card name="yuque">` 嵌入链接**：语雀文档嵌入卡片
3. **纯文本 URL**：正文中以 `http://` 或 `https://` 开头的文本（常见于从其他文档复制粘贴时遗留的裸 URL）

清洗时，`lake-extract.py` 会自动识别前两种形式。**第三种形式需要 AI 在 Step 0 内容清点时主动扫描正文，识别纯文本 URL 并计入链接数量。** 这是 AI 常见的遗漏点——纯文本 URL 不是格式标记，是内容，不可当作格式剥离。

## Step 0 内容清单

在规划阶段（Step 0），必须完成以下内容清点，并记录在规划表中：

```
| 内容清单 | 图片×N 链接×N 代码块×N 表格×N 附件×N 数学公式×N 流程图×N 话术×N |
```

这个清单是后续所有质量门的校验基准：
- 门 1（清洗后）：清洗后的标记数量 ≥ Step 0 清单数量
- 门 2（梳理后）：梳理大纲中每个不可变元素都有对应位置
- 门 4（输出后）：`verify-content.py` 确认输出中的不可变元素数量 ≥ Step 0 清单数量

## 与各文档类型的关系

各文档类型写作指南中的"特殊保留规则"是本基线的**超集**——它们在基线之上追加文档类型特有的保留项。例如：

- SOP 追加：审批权限矩阵、Check List 项目
- API 文档追加：调用示例（可直接复制执行）、错误码
- 技术文档追加：架构图、性能指标量化值
- 教程追加：可运行代码示例、预期输出

当文档类型的"内容取舍规则"与本清单冲突时，**本清单优先**。取舍规则可以授权"归类"或"简化"，但不能授权"删除"任何不可变元素。
