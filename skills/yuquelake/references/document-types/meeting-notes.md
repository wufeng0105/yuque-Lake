# 会议记录

## 章节骨架

1. **会议信息** — 标题、时间、地点、主持人、记录人
2. **出席人员** — 参会人员列表、缺席人员
3. **议程** — 本次会议讨论事项列表
4. **讨论记录** — 每个议程项的讨论要点
5. **决议** — 会议达成的决定
6. **行动项** — 任务、负责人、截止日期
7. **下次会议** — 时间、地点、预期议程

## 推荐 Lake Card

| 章节 | 推荐 Card |
|------|----------|
| 出席人员 | `<table>` |
| 讨论记录 | `<card-collapse>` 每个议题折叠 |
| 决议 | `<card-label label="决议">` |
| 行动项 | `<table>` |
| 下次会议 | `<card-date>` |
