# 文档结构化方法论参考

> 本文件汇总了用于约束文档结构化过程的方法论。这些方法论的作用不是限制大模型的思考能力，而是约束输出流程和结构质量。

## 一、Information Mapping（信息映射法）

> Robert E. Horn, 1965。一种以研究为基础的结构化写作方法。

### 6 种信息类型

任何文档内容必然属于以下六种类型之一。判断文档类型后，将每个内容块归类到对应类型：

| 信息类型 | 说明 | 典型场景 |
|---------|------|---------|
| Procedure（步骤） | 完成任务需要执行的一系列步骤 | 操作手册、SOP |
| Process（过程） | 随时间推移相继发生的事件/状态变化 | 流程说明、生命周期 |
| Principle（原理） | 用于规定、引导或请求行为的陈述 | 规范、标准、准则 |
| Concept（概念） | 具有相同关键属性的一类或一组事物 | 概念解释、术语定义 |
| Structure（结构） | 包含零部件或边界的事物的描述 | 架构说明、系统组成 |
| Fact（事实） | 被认为是真实的陈述 | 数据、统计、事实陈述 |

### 6 条组织原则

| 原则 | 约束 |
|------|------|
| 组块（Chunking） | 将信息分解为小的、易管理的单元（7±2 个信息块） |
| 相关性（Relevance） | 每个信息单元仅限于单个主题 |
| 贴标签（Labeling） | 给每个信息单元添加可识别其内容的标签 |
| 一致性（Consistency） | 术语、组织、格式和顺序要一致 |
| 易访问（Accessibility） | 需要详细信息的读者可快速访问，不需要的可跳过 |
| 图文结合 | 采用文本和图形结合的方式 |

### 5 个分析阶段

1. **预写作分析**：分析受众和内容
2. **信息收集分析**：收集内容，确定部分间关系
3. **组织分析**：内容-主题-关键块矩阵
4. **排序分析**：按任务排列块顺序
5. **呈现分析**：适配输出格式

## 二、DITA（达尔文信息类型架构）

> IBM/OASIS, 2005。基于 XML 的结构化写作标准。

### 3 种主题类型

| 主题类型 | 回答的问题 | 结构约束 |
|---------|----------|---------|
| Concept（概念） | 是什么？为什么？ | 原理、背景与抽象理解 |
| Task（任务） | 怎么做？ | 步骤导向，原子性、有序性、可执行性 |
| Reference（参考） | 查什么？ | 精确、静态、查表式信息 |

核心思想：**强类型约束**——不允许内容混杂，每个内容块必须明确属于一种类型。

## 三、Minimalism（极简主义）

> John Carroll, 1990。以行动为导向的文档设计方法。

### 核心原则

- **以行动为导向**：不是先讲理论，而是让用户先动手
- **以任务为焦点**：只保留完成任务所需的信息，砍掉无关内容
- **分层**：详细信息放在折叠/次级层级，不打扰主流程
- **简洁是结果不是目标**：聚焦任务后自然变简洁

> Carroll："简洁更多是极简主义的后果，而非极简主义的原则。"

## 四、ISO 24183:2024 技术传播质量 6 原则

| 原则 | 说明 |
|------|------|
| Completeness（完整性） | 覆盖所有必要信息 |
| Minimalism（极简性） | 只包含相关内容 |
| Correctness（正确性） | 技术准确 |
| Conciseness（简洁性） | 避免不必要的细节 |
| Consistency（一致性） | 全文属性统一 |
| Comprehensibility（可理解性） | 目标读者能看懂 |

## 五、结构化技术写作流程

> 刘阳《结构化的技术写作与内容管理》

1. **研究阶段** → 研究用户、产品、现有内容
2. **设计阶段** → 设计文档类型体系、内容模型、内容模块
3. **结构评审** → 评审结构是否合理
4. **结构标准化** → 将结构标准化为模板
5. **写作** → 按模板和原则填充内容
6. **内容评审** → 质量检查

## 六、方法论在本 skill 中的作用

这些方法论不是用来"教"大模型理解内容的——大模型自己就能理解。

方法论的作用是**约束流程和输出**：

| 方法论 | 约束什么 |
|--------|---------|
| Information Mapping 6 种信息类型 | 约束内容分类：每个内容块必须归为 6 种类型之一 |
| Information Mapping 6 条原则 | 约束内容组织：组块、相关性、标签、一致性、可访问性 |
| DITA 3 种主题类型 | 约束文档结构：按 Concept/Task/Reference 组织 |
| Minimalism | 约束内容取舍：只保留任务相关信息 |
| ISO 6 原则 | 约束质量检查：最终输出必须通过 6 项检查 |
| 结构化写作 6 阶段 | 约束工作流程：研究→设计→评审→标准化→写作→评审 |
