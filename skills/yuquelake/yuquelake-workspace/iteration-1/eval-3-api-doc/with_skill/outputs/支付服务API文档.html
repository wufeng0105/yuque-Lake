支付服务 API 文档

接口总览

方法路径认证说明
POST/api/v1/paymentsBearer Token创建支付订单
GET/api/v1/payments/:idBearer Token查询支付状态
POST/api/v1/refundsBearer Token发起退款

创建支付订单

请求参数

参数名类型必填说明
amountnumber是支付金额（分）
currencystring是币种（CNY/USD）
methodstring是支付方式（alipay/wechat/bank）
order_idstring是商户订单号
notify_urlstring否回调通知地址

响应示例

{ "code": 0, "data": { "payment_id": "pay_202608081234", "status": "pending", "amount": 10000, "currency": "CNY", "method": "alipay", "created_at": "2026-08-08T14:00:00Z" } }

错误码

错误码含义说明
40001INVALID_PARAM请求参数错误
40003UNAUTHORIZED认证失败或 token 过期
40901DUPLICATE_ORDER订单号重复
50001SYSTEM_ERROR系统内部错误

认证流程

sequenceDiagram participant C as Client participant A as Auth Server participant P as Payment Service C->>A: POST /auth/token (key + secret) A-->>C: access_token (2h) C->>P: POST /payments (Bearer token) P-->>C: payment_id
