一、环境准备

1.1 安装 Docker Engine 27.0+

Docker 27.0 版本带来了对 containerd 2.0 的原生支持和多架构构建增强。

安装步骤（Ubuntu 22.04 LTS）：

# 卸载旧版本 sudo apt-get remove docker docker-engine docker.io containerd runc # 安装依赖 sudo apt-get update sudo apt-get install ca-certificates curl gnupg lsb-release # 添加 Docker 官方 GPG 密钥 sudo install -m 0755 -d /etc/apt/keyrings curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg sudo chmod a+r /etc/apt/keyrings/docker.gpg # 设置稳定版仓库 echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null # 安装最新版本 Docker Engine sudo apt-get update sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin # 验证安装 sudo docker --version # 应显示: Docker Engine - Community 27.0.x

配置 Docker 以非 root 用户运行（安全最佳实践）：

sudo usermod -aG docker $USER newgrp docker # 无需重启即可生效

1.2 部署 Kubernetes 1.30 集群

使用 kubeadm 部署最新稳定版 K8s 1.30。

前置条件检查：

检查项要求验证命令
操作系统Ubuntu 22.04+cat /etc/os-release
内存≥ 4GBfree -h
CPU≥ 2核nproc
磁盘空间≥ 50GBdf -h /
Swap已关闭swapon --show
端口6443, 2379-2380, 10250-10252 可用netstat -tlnp

安装 containerd：

# 安装 containerd 2.0 sudo apt-get install containerd # 生成默认配置 sudo mkdir -p /etc/containerd containerd config default | sudo tee /etc/containerd/config.toml # 修改 SystemdCgroup 设置 sudo sed -i 's/SystemdCgroup \= false/SystemdCgroup \= true/g' /etc/containerd/config.toml # 重启 containerd sudo systemctl restart containerd sudo systemctl enable containerd

安装 kubeadm, kubelet, kubectl：

# 关闭 swap sudo swapoff -a sudo sed -i '/swap/s/^/#/' /etc/fstab # 加载内核模块 sudo modprobe overlay sudo modprobe br_netfilter # 设置内核参数 cat <<EOF | sudo tee /etc/sysctl.d/kubernetes.conf net.bridge.bridge-nf-call-iptables = 1 net.bridge.bridge-nf-call-ip6tables = 1 net.ipv4.ip_forward = 1 EOF sudo sysctl --system # 添加 Kubernetes 仓库 echo "deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.30/deb/ /" | sudo tee /etc/apt/sources.list.d/kubernetes.list curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.30/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg # 安装 sudo apt-get update sudo apt-get install kubelet kubeadm kubectl sudo apt-mark hold kubelet kubeadm kubectl

初始化 Master 节点：

sudo kubeadm init \ --apiserver-advertise-address=10.0.0.10 \ --pod-network-cidr=10.244.0.0/16 \ --kubernetes-version=v1.30.0 # 配置 kubectl mkdir -p $HOME/.kube sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config sudo chown $(id -u):$(id -g) $HOME/.kube/config # 验证 kubectl get nodes

加入 Worker 节点：

# 在 Worker 节点执行（token 来自 init 输出） sudo kubeadm join 10.0.0.10:6443 \ --token abcdef.0123456789abcdef \ --discovery-token-ca-cert-hash sha256:xxxxx

安装网络插件（Calico）：

kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.27.0/manifests/calico.yaml

二、应用容器化

2.1 编写 Dockerfile

Spring Boot 应用 Dockerfile 示例：

# 多阶段构建 # 阶段1: 构建 FROM maven:3.9-eclipse-temurin-17 AS builder WORKDIR /app COPY pom.xml . RUN mvn dependency:go-offline COPY src ./src RUN mvn package -DskipTests # 阶段2: 运行 FROM eclipse-temurin:17-jre-alpine WORKDIR /app # 安装必要的工具 RUN apk add --no-cache curl tzdata && \ cp /usr/share/zoneinfo/Asia/Shanghai /etc/localtime && \ echo "Asia/Shanghai" > /etc/timezone # 复制构建产物 COPY --from=builder /app/target/*.jar app.jar # 健康检查 HEALTHCHECK --interval=30s --timeout=3s --retries=3 \ CMD curl -f http://localhost:8080/actuator/health || exit 1 # 暴露端口 EXPOSE 8080 # JVM参数 ENV JAVA_OPTS="-Xms512m -Xmx512m -XX:+UseG1GC -XX:MaxGCPauseMillis=200" # 启动命令 ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar"]

2.2 构建和推送镜像

# 构建镜像 docker build -t registry.example.com/order-service:v4.0.0 . # 多架构构建（AMD64 + ARM64） docker buildx build --platform linux/amd64,linux/arm64 \ -t registry.example.com/order-service:v4.0.0 \ --push . # 登录私有仓库 docker login registry.example.com -u admin -p <password> # 推送镜像 docker push registry.example.com/order-service:v4.0.0

2.3 镜像优化最佳实践

优化项说明效果
多阶段构建分离构建环境和运行环境镜像减小60%+
使用Alpine基础镜像替代完整OS镜像镜像减小80%
合并RUN指令减少镜像层数减少镜像大小
.dockerignore排除不必要文件加快构建速度
使用构建缓存依赖先复制再复制源码加快构建速度

七、安全加固

7.1 容器安全

安全项配置说明
非root用户运行USER 1000:1000避免root权限
只读文件系统readOnlyRootFilesystem: true防止恶意写入
禁用特权privileged: false最小权限原则
能力裁剪drop: ["ALL"]移除所有Linux能力
安全上下文runAsNonRoot: true强制非root

7.2 Pod Security Standards

八、故障排查

8.1 常用排查命令

场景命令说明
查看Pod状态kubectl get pods -n production检查Pod运行状态
查看Pod详情kubectl describe pod <pod-name> -n production排查启动失败
查看容器日志kubectl logs <pod-name> -n production查看应用日志
查看上一容器日志kubectl logs <pod-name> --previous -n production崩溃前日志
进入容器kubectl exec -it <pod-name> -- /bin/sh容器内调试
查看事件kubectl get events -n production --sort-by='.lastTimestamp'排查调度问题
端口转发kubectl port-forward <pod-name> 8080:8080本地访问Pod
查看资源使用kubectl top pods -n productionCPU/内存使用

8.2 常见问题

问题可能原因解决方案
ImagePullBackOff镜像不存在/无权限检查镜像名和Secret
CrashLoopBackOff应用启动失败查看日志，检查配置
OOMKilled内存不足调整resources.limits
Pending资源不足/调度失败检查节点资源，查看events
健康检查失败应用未就绪检查探针配置和应用状态
