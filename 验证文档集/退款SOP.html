用户退款标准操作程序

目的

规范用户退款流程，确保退款金额核算准确、审批合规、执行可追溯。

范围

适用于所有付费用户的退款申请处理。不适用于纯技术故障退款（走专项流程）。

定义与术语

充值折扣用户充值时享受的折扣比例（如 0.75 表示七五折）
邀请返利用户通过邀请链接获得的奖励余额
按量付费按实际使用量计费的模式，余额永久有效
支付手续费支付渠道收取的手续费，按支付金额的 0.6% 计算

职责

客服接待用户、收集材料、核算金额、登记周报
主管（杰哥）确认退款金额
阿飞执行打款、注销账号
阿滨执行打款
张总报销审批

退款规则

有效期大于等于 14 天：支持按剩余价值退款。

有效期小于 14 天：支持折半转成按量付费额度。

常规退款统一收 20% 手续费，手续费超过 100 元按 100 元计。

常规规则是尽可能解决用户问题、留住用户、不走退款。

可引导用户转按量付费（永久有效，随时可用）。

实在解决不了或用户闹事的，再沟通退款。

操作步骤

话术：您是什么原因要退款呢？

  • 如果是使用问题，先发群里确认是否可以帮用户解决
  • 订阅用户可引导按 50% 规则转按量付费
  • 退款原因要记录到周报

确认用户退款后，发话术给用户收集以下材料：

话术：这样，您给我 1. 网站注册账号 2. 订阅的付款截图（需要能看到日期） 3. 仪表盘截图：https://www.aicodemirror.com/dashboard 4. 邀请返利截图：https://www.aicodemirror.com/dashboard/invite-rewards 5. 您的开票抬头或者邮箱

话术：我们将根据您的用量情况，核算退款金额，请您稍等。退款后会注销账号请您知悉。账号注销后将永久冻结，不能再注册使用。

多选聊天记录，转发大群，简要说明退款原因，请杰哥确认。确认后核算退款金额。

退款计算公式

(余额 - 邀请返利) x 充值折扣 - 支付金额 x 0.6%手续费 - 充值金额 x 20%手续费(封顶100) = 应退金额

正常退款扣除充值金额 x 0.6% 的支付手续费，然后找主管核对邀请返利扣除方式。

邀请返利扣除规则

  1. 扣除邀请人的邀请奖励积分（邀请奖励账户余额）
  2. 扣除邀请人的奖励积分（按量付费余额）
  3. 扣除被邀请人的（按充值金额 20% 扣除，最高 100）
  • 退款金额在 100 以内不要扣被邀请人的
  • 如果用户反应大就不扣
  • 用户本身有邀请返利也需要扣除（计算转入钱包的金额，没有转入则不计算）

计算示例

用户余额为 1000，参与邀请返利，充值折扣 0.75：

退款金额 = (1000 - 邀请返利) x 0.75 - 支付手续费 = 750 - 1259 x 0.2 = 498.2

邀请返利有就扣除，没有则不扣除。

检查用户是否有发票需要作废。作废后按照实际使用金额重新登记开票。

不要直接问是否开过发票。拿到开票信息后查询系统开票情况，再告知用户会作废并重新开具。

话术：您好，麻烦您告诉我下您的开票信息：抬头，收发票的邮箱哈

登记退款记录到周报。

用户确认后，请用户添加阿飞企业微信退款。

话术：确认金额无误后请加企业微信，为您返款。

请用户提交注册手机号，检查周报，确认退款金额，给用户打款。打款完毕后更新周报记录。

在客服 88888 群提交注销账号。

话术：15810032255 退款完毕，请注销账号。

注销账号操作

  1. 登录管理后台 https://admin.aicodemirror.com/anthropic/management，在【用户管理】页面输入用户手机号
  2. 查询到用户后，先冻结账号
  3. 选择删除账号，并在弹出提示确定
  4. 重新输入用户手机号，查询确认（没有找到匹配的用户），注销成功

按照周或者累计金额，核算总退款金额，找张总报销。
  1. 分析本周退款条数和原因，复盘沟通过程
  2. 明确用户退款根本原因和诉求，寻求对应优化方案，降低后续该原因退款

Check List

  • 确认退款金额计算无误
  • 确认已登记的发票作废完成
  • 确认账号注销
